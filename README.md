# Project Title
Finding the Hypotenuse of a Right Triangle Using the Math
Library
## Description
The program calculates the hypotenuse of a right triangle
## How to Run
Open the given file, then press shift+f10
## Input Needed
Length of side a and b
## Sample Output
import math

lengtha = float(input("Whats the length of side a: "))
lengthb = float(input("Whats the length of side b: "))

hypotenuse = math.sqrt(math.pow(lengtha, 2) + math.pow(lengthb, 2))

print(f"The hypotenuse is {hypotenuse:.2f}")
